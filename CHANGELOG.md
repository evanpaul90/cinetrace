# Changelog

## 0.3.0 - 2026-09-02

- Added deterministic same-build control runs with screenshot, state, environment and oracle
  fingerprints.
- Added pre-navigation adapter preparation for clocks, seeded randomness and public capture seams.
- Added Firefox and WebKit coverage for the generic audit corpus.
- Added forced WebGL failure, no-JavaScript, keyboard, overlay, reduced-motion and page-error checks.
- Added explicit detection for late scroll-geometry mutation and screenshot-path collisions.
- Published the exact Odessis production adapter, complete sanitized control reports, SHA-256
  manifest and inspectable sample filmstrip.

The project remains source-distributed. No npm package is published for this release.
