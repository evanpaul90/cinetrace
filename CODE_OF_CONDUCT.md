# Code of conduct

CineTrace contributors and maintainers commit to a respectful, harassment-free project space.

## Expected behaviour

- Discuss code, evidence and trade-offs without attacking people.
- Give specific, reproducible feedback and accept correction when the evidence changes.
- Respect different backgrounds, identities, experience levels and accessibility needs.
- Keep private vulnerability reports and personal information private.

Harassment, discriminatory language, threats, sustained disruption and publishing another person's
private information are not accepted. Maintainers may edit or remove contributions and restrict
participation when this policy is violated. Serious abuse should also be reported through GitHub's
Report abuse mechanism so it can be handled privately.

This policy applies in repository issues, pull requests, discussions and other project spaces.
